# BookingApp API

RESTful API сервис для системы управления отелями и бронированиями. 
Проект разрабатывается с упором на слоистую архитектуру (Layered Architecture), принципы DDD (Domain-Driven Design) и строгую инкапсуляцию бизнес-логики.

## Стек технологий
* **Язык:** C# (.NET 10)
* **Фреймворк:** ASP.NET Core Web API
* **База данных:** MS SQL Server (LocalDB) + Entity Framework Core (Code-First)
* **Архитектура:** Layered Architecture, Dependency Injection (DI), Data Transfer Objects (DTO)

## Ключевые архитектурные решения
* **Разделение на слои:** Строгое разделение проекта на независимые слои `Domain` (ядро), `Infrastructure` (работа с БД) и `API` (контроллеры и транспорт).
* **Богатая предметная область (Rich Domain Model):** Использование строгой инкапсуляции (`private set`, `init`). Сущности защищены от создания в невалидном состоянии благодаря проверкам (Fail-fast) прямо в конструкторах.
* **Изоляция данных:** Использование неизменяемых DTO (с модификаторами `required` и `init`) для сокрытия внутренней структуры базы данных от внешних клиентов.
* **Ручной маппинг:** Отказ от автомапперов в пользу прозрачного ручного преобразования DTO в сущности на уровне слоя сервисов (`Services`).
* **Настройки БД через Fluent API:** Вынос конфигураций таблиц (например, точность цен `HasPrecision` и ограничения `Check Constraint`) в контекст базы данных, оставляя классы сущностей чистыми.

## Текущий функционал (Endpoints)

На данный момент реализовано базовое создание сущностей (остальной CRUD в разработке). 
Для тестирования запросов используется файл `requests.http`.

**Hotels:**
* `POST /api/hotels` — создать новый отель.

**Rooms:**
* `POST /api/rooms` — добавить новую комнату (с обязательной привязкой к существующему `HotelId`).
