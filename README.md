# Booking API

RESTful API сервис для системы управления отелями, номерами и бронированиями. 

Проект разработан с упором на чистый код и **Layered Architecture** (слоистую архитектуру), чтобы продемонстрировать изоляцию бизнес-логики от логики обработки HTTP-запросов.

## Стек технологий
* **Язык:** C# (.NET 8/9)
* **Фреймворк:** ASP.NET Core Web API
* **База данных:** Entity Framework Core (Code-First)
* **Архитектурные паттерны:** Dependency Injection (DI), Data Transfer Objects (DTO)

## Ключевые архитектурные решения
* **Слоистая архитектура:** Строгое разделение на Controllers (маршрутизация) и Services (бизнес-логика).
* **Изоляция данных:** Использование DTO для скрытия внутренней структуры базы данных от внешних клиентов.
* **Бизнес-валидация:** Реализована проверка пересечения дат (`CheckInDate` / `CheckOutDate`), не позволяющая забронировать уже занятый номер.
* **Внедрение зависимостей:** Управление временем жизни сервисов через встроенный DI-контейнер ASP.NET.

## Основной функционал (Endpoints)

**Hotels**
* `GET /api/hotels` — получить список отелей
* `POST /api/hotels` — добавить новый отель

**Rooms**
* `GET /api/rooms` — получить список всех номеров с привязкой к отелям
* `POST /api/rooms` — добавить номер
* `PUT /api/rooms/{id}` — обновить данные номера
* `DELETE /api/rooms/{id}` — удалить номер

**Bookings**
* `POST /api/bookings` — создать новое бронирование (с проверкой доступности дат)
